Sicurezza

Misure tecniche e organizzative adottate per il servizio GiroFacile

1. Principi generali

GiroFacile adotta misure tecniche e organizzative proporzionate alla fase di sviluppo e al tipo di dati trattati, con l’obiettivo di proteggere account, dati aziendali e dati operativi delle consegne.

2. Accesso e ruoli

  • account amministratore/azienda;
  • portale autista separato;
  • portale agente separato;
  • funzioni e permessi distinti per ruolo;
  • sezioni premium bloccate in base al piano.

3. Password e recupero accesso

Le password sono gestite con meccanismi di autenticazione e recupero tramite token temporanei. Il recupero password avviene tramite link valido per un tempo limitato e non tramite invio della password in chiaro.

4. Connessione sicura

Il servizio è erogato tramite connessione HTTPS sul dominio ufficiale https://girofacile.it, ove configurato con certificato SSL valido.

5. Database

Allo stato attuale il servizio utilizza un database SQLite. È prevista, per una fase di crescita e maggiore scalabilità, una futura migrazione a PostgreSQL o database professionale equivalente.

6. Mappe e API

Le integrazioni con Google Maps Platform sono configurate tramite chiavi API e limiti di utilizzo. Le coordinate dei clienti vengono salvate dopo verifica manuale dell’indirizzo, per ridurre chiamate inutili e migliorare il controllo dei costi.

7. Backup

La strategia di backup può variare in base all’ambiente di hosting e alla fase commerciale del servizio. Prima dell’utilizzo commerciale su larga scala si raccomanda l’attivazione di backup automatici periodici e conservazione sicura fuori server.

8. Limitazioni

Le misure di sicurezza vengono aggiornate progressivamente. Nessun sistema informatico può garantire sicurezza assoluta, ma GiroFacile mira a ridurre i rischi con misure adeguate alla natura del servizio.
