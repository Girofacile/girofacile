Database Viewer

Visualizzazione in sola lettura delle tabelle database, stile Excel, con campi sensibili mascherati.

Le password, i token, le chiavi API e i segreti vengono sempre mascherati. La prima versione è in sola lettura per evitare modifiche accidentali ai dati.

Clicca “Apri database” per caricare le tabelle.
